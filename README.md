# Unhook for Gemini
It is a cross-browser (Chrome, Firefox, Edge) and lightweight web extension that removes distracting elements from Gemini to allow for a more focused use.

---

## Features

- **Hide Distracting Elements:** From greeting message to search, chat history, promotional sections, and upgrade to pro button.
- **Native Dark Mode:** Supports both light and dark mode, it automatically adapts to your system theme.
- **Fast & Modern:** Built with vanilla JS and CSS using Google beautiful UI components and font.
